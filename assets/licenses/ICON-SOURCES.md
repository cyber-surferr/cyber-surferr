# Font & icon sources
- Space Grotesk (500/700) - SIL OFL 1.1, via @fontsource/space-grotesk. Subset to Latin, embedded as base64 WOFF2.
- JetBrains Mono (500) - SIL OFL 1.1, via @fontsource/jetbrains-mono. Subset to Latin, embedded as base64 WOFF2.
- Brand icons (Python, C++, OpenJDK/Java, JavaScript, HTML5, CSS3, MongoDB, Express, React, Node.js, GitHub, LinkedIn, Gmail): Simple Icons v13.21.0 (CC0 1.0).
  Pinned to v13.21.0 because newer Simple Icons releases removed the LinkedIn mark. Brand marks remain trademarks of their owners.
- Not from Simple Icons (generic glyphs drawn for this project, not brand marks): none and "SQL" (a language, not a brand - generic database glyph).
- Java is shown with the OpenJDK mark from Simple Icons (Simple Icons has no separate Java mark).
